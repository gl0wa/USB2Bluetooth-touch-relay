Usb2BT Touch

Make a USB touchscreen work wirelessly with an Android TV that has no free USB port. Repository · User guide

Tested combination: only one monitor and one Android TV device have been tested so far (see the repository). Other screens and hosts may behave differently.

Install

Flashing needs desktop Chrome or Edge (Web Serial). It does not work from a phone browser, Firefox or Safari.

  1. Unplug the StampS3 from the monitor (if connected there).
  2. Connect the StampS3 to the computer with a data USB-C cable.
  3. Click Install and pick the serial port. The user build has no Wi-Fi; erasing on install also removes the Bluetooth pairing, so re-pair afterwards.
  4. If the port does not appear or flashing fails: unplug, hold the button while plugging in, then retry (ROM download mode; bad firmware cannot disable it).
  5. Move the cable to the monitor's touch port, then pair from the Android TV: Settings → Remotes & Accessories → Add accessory → “Usb2BT Touch”.

Install erases the device (new_install_prompt_erase in the manifest), which clears Wi-Fi-era leftovers and the Bluetooth bond. Pair again after flashing.

What each option means

  • Gestures on (default): for Android TV and other screens with no on-screen Back or Home. Swipe in from the left edge for Back, up from the bottom edge for Home; swipe down from the top edge toggles D-pad mode for controls that ignore touch.
  • Gestures off: when the target has its own navigation, or when touches at the screen edges must respond with no delay at all (kiosk, drawing app). Also disables D-pad mode and the button's Back.
  • Bluetooth mode, Android (default): needed for Back, Home and D-pad. Uses a non-standard report format verified only on one Android TV device.
  • Bluetooth mode, Standard: try on devices that are not Android, or if touch misbehaves after pairing (Windows, Linux, iPad). Touch only, no navigation keys. Needs a reboot and re-pair. No device other than the tested one has been tried, so these are expectations, not tested results.
  • Forget pairings: moving the gateway to another TV, or when it will not reconnect. Also remove the device on the Android side.
  • Reboot: applies a Bluetooth-mode change (re-pair too).
